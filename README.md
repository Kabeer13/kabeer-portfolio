# Kabeer — The Golden Garage

A static personal portfolio with a maximalist automotive-luxury art direction, gold chain corner ornaments, a responsive project archive, and interactive project dossiers.

## Run locally

No build tools or paid services are required. Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Personalise before submission

- Your portrait is already integrated at `assets/kabeer-portrait.jpg`. To change it later, replace that file while keeping the same filename, or update the image path in `index.html`.
- Review the project cards in `index.html`. Each card has a real repository URL and an editable description. Keep project claims accurate.
- Add your preferred public contact links in the Contact section if you want more than GitHub.
- Update the skill list if your current skills or interests change.

## Deploy on GitHub Pages

1. Create a new **public** repository on GitHub (for example `kabeer-portfolio`).
2. Upload the contents of this folder to the repository root (not the containing folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will usually be `https://kabeer13.github.io/kabeer-portfolio/` if the account is `Kabeer13` and the repository is named `kabeer-portfolio`.
6. Open the live URL in a private/incognito window and test all links and mobile layout before submitting.

## Notes

- The GitHub public API is used as a nonessential enhancement; the portfolio still works if that request fails.
- The Car Decision System is labelled as a concept/in-progress project and links to the profile until a dedicated repository URL is available.
- The visual design is original and does not use Versace logos or campaign artwork.
